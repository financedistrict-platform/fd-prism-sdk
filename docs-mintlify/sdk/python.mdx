## Overview

The Python SDK protects API routes with x402 micropayments. Each framework has its own package. All of them share `prism-sdk-core` for route matching, payment verification and settlement.

## Flask

```python
from flask import Flask, jsonify
from prism_flask import get_payer, prism_payment_middleware
from prism_sdk_core import PrismMiddlewareConfig, RoutePaymentConfig

app = Flask(__name__)

prism_payment_middleware(
    app,
    PrismMiddlewareConfig(api_key='your-api-key'),
    {
        '/api/premium': RoutePaymentConfig(price=0.01, description='Premium API access'),
        '/api/data/*': RoutePaymentConfig(price=0.005, description='Data API access'),
    },
)

@app.route('/api/premium')
def premium():
    return jsonify({'message': 'Premium content', 'payer': get_payer()})
```

## FastAPI

```python
from fastapi import FastAPI, Request
from prism_fastapi import add_prism_middleware, get_payer
from prism_sdk_core import PrismMiddlewareConfig, RoutePaymentConfig

app = FastAPI()

add_prism_middleware(
    app,
    PrismMiddlewareConfig(api_key='your-api-key'),
    {
        '/api/premium': RoutePaymentConfig(price=0.01, description='Premium API access'),
        '/api/data/*': RoutePaymentConfig(price=0.005, description='Data API access'),
    },
)

@app.get('/api/premium')
async def premium(request: Request):
    return {'message': 'Premium content', 'payer': get_payer(request)}
```

## Django

```python
MIDDLEWARE = [
    'prism_django.PrismPaymentMiddleware',
]

PRISM_CONFIG = {
    'API_KEY': 'your-api-key',
    'ROUTES': {
        '/api/premium/': {'price': 0.01, 'description': 'Premium API access'},
        '/api/data/*': {'price': 0.005, 'description': 'Data API access'},
    },
}
```

```python
from django.http import JsonResponse
from prism_django import get_payer

def premium(request):
    return JsonResponse({'message': 'Premium content', 'payer': get_payer(request)})
```

Django raises `ImproperlyConfigured` at startup when `PRISM_CONFIG` has an unknown key, lacks `API_KEY` or `ROUTES`, or when a leftover `PRISM_ROUTES` setting is defined.

## Route Patterns

- `/api/data/*` protects `/api/data` and every path below it. The match stops at a `/` boundary, so `/api/data/users` is protected and `/api/database` is not.
- A route without `*` (for example `/api/premium`) covers that path and everything below it.
- `*` is only allowed as a trailing `/*`. Patterns such as `/api/*/users` or `/api*` are rejected when the middleware is set up.
- An exact match is used first.
- A route value is a `RoutePaymentConfig`, or a dict with only `price`, `description` and optionally `currency`. Unknown or missing keys are rejected at setup, so a typo can never leave a route unprotected.

## Reading the Payment

| Framework | Payer | Full payment |
|-----------|-------|--------------|
| Flask | `get_payer()` | `get_payment()` |
| FastAPI | `get_payer(request)` | `get_payment(request)` |
| Django | `get_payer(request)` | `get_payment(request)` |

Each helper returns `None` when no payment was verified for the request.
