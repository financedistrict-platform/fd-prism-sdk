# prism-sdk-core

Framework-independent core of the Prism x402 Python SDK: the gateway client, payment-header handling and the verify/settle flow shared by the Flask, FastAPI and Django adapters.

Most applications install a framework adapter (`prism-flask`, `prism-fastapi` or `prism-django`), which depends on this package.

See the [Python SDK guide](../../README.md) for usage.
